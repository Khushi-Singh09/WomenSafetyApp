# 🛡️ Women Safety App

A mobile application designed to ensure the safety of women by providing emergency features like location sharing, SOS alerts, and more.

## 🚀 Features
- 📍 Live Location Tracking
- 🆘 One-Tap SOS Alert
- 📞 Emergency Contacts Integration
- 🔊 Loud Siren Alert
- 📡 Real-time Location Sharing via SMS
- 📁 Local Data Storage of Incidents

## 🛠️ Tech Stack
- **Frontend:**  Android 
- **Backend:** Firebase 
- **APIs:** Google Maps API, SMS Gateway
